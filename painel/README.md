# Painel ExpressChat Remoto

Painel web (rustdesk-api-web, commit 3998c2a) com logo ExpressChat, idioma
Português como padrão e tela de Dashboard.

- `admin.tar.gz`: build pronto (`npm run build`, conteúdo de `dist/`).
- `painel-web.patch`: alterações aplicadas sobre lejianwen/rustdesk-api-web.
- `Dockerfile`: imagem lejianwen/rustdesk-api com o painel trocado; usado no Easypanel.
